# RideNow AI — UI Design System

## Concrete visual identity (see `docs/DESIGN_REFERENCE.md` for full detail)
Dark theme: navy background (`#0b1329`), card surfaces (`#1e293b`/`#0f172a`), teal accent for AI/recommended items (`#0d9488`/`#2dd4bf`), green for safety/eco (`#4ade80`/`#34d399`), red for anomaly/SOS (`#ef4444`/`#dc2626`). This is not a suggestion to riff on — it's the actual agreed palette from real reference mockups. The sections below (layout, navigation, imagery, states) still apply on top of it.

## Design Goal
Create a premium intelligent mobility interface that feels trustworthy, modern and purposeful.

## Visual Personality
- Intelligent
- Safe
- Urban
- Clean
- Human
- Sustainable
- Technology-aware

Avoid making the product look like a generic taxi-booking clone.

## Layout Principles
- Strong hierarchy
- Intentional whitespace
- Clear primary action
- Limited card density
- Consistent spacing
- Mobile-first behavior
- Avoid decorative clutter

## Navigation
Use a distinctive navigation pattern rather than a standard basic navbar.

The navigation must make the current location obvious and must not create duplicate entry points for the same feature.

## Imagery
Use real, relevant imagery where it improves communication:
- mobility
- urban travel
- vehicles
- people using transportation
- sustainability

Avoid unrelated stock images.

Every image needs a content reason.

## UI States
Use consistent states for:
- loading
- empty
- error
- success
- warning
- selected
- disabled
- active

## AI Visualization
Use clear score treatments for:
- Safety
- Eco
- Recommendation
- Fare prediction

Avoid excessive glowing AI effects.

## Cards
Cards should group meaningful information. Do not turn every text block into a card.

## Buttons
Primary actions must be visually distinct.
Secondary actions should not compete with the primary action.

## Forms
Inputs should have:
- clear labels
- useful placeholders
- validation feedback
- focus states
- mobile-friendly sizing

## Maps
Maps are functional product surfaces, not decorative backgrounds.

## Responsive
Design and test for:
- mobile
- tablet
- laptop
- desktop

Pay special attention to:
- navigation
- map height
- cards
- forms
- charts
- bottom action areas
