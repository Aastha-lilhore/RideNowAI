# Docs

| File | What it's for |
| --- | --- |
| `REQUIREMENTS.md` | What each screen/feature must do |
| `API_CONTRACT.md` | Shared database schema and endpoints (frontend, backend and ML all build against it) |
| `AI_FORMULAS.md` | Scoring formulas: fare, safety, eco, recommendation, route anomaly |
| `BACKEND_INTEGRATION.md` | Frontend wiring status: what's connected to real endpoints and what still needs one |
| `FRONTEND_ARCHITECTURE.md` | How the frontend is organised |
| `UI_DESIGN_SYSTEM.md`, `DESIGN_REFERENCE.md` | Design rules. Note: `DESIGN_REFERENCE.md` predates the final amber theme, so use its layout patterns but not its colours |
| `DECISIONS.md` | Decisions made and why |
| `CONTRIBUTING.md` | Working agreements, commit style, running the tests |
| `PROJECT_MEMORY.md` | Running progress log |
